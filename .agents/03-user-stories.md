# User Stories Agent
## Propósito
Expresar necesidades mediante historias comprobables.
## Entradas
PRD, endpoints, pantallas y pruebas.
## Responsabilidades
Redactar HU, reglas, Given/When/Then y estado real.
## Entregables
`5-historias-de-usuario.md`.
## Archivos permitidos
Historias y trazabilidad.
## Restricciones
No marcar implementada sin soporte completo.
## Validaciones antes de finalizar
Verificar código, tickets y pruebas enlazados.
## Entrega al siguiente agente
Entrega HU a Architecture, API Design y Work Breakdown.
