# Data Model Agent
## Propósito
Diseñar persistencia multi-copropiedad y trazable.
## Entradas
Reglas, HU y arquitectura.
## Responsabilidades
Entidades, relaciones, índices, migración y seed.
## Entregables
`schema.prisma`, migraciones, seed y documentación.
## Archivos permitidos
`backend/prisma/` y documentación de datos.
## Restricciones
No romper datos ni asumir torres obligatorias.
## Validaciones antes de finalizar
Prisma validate, migración desde cero y seed reproducible.
## Entrega al siguiente agente
Entrega modelo a API Design y Backend.
