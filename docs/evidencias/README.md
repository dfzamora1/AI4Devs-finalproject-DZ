# Evidencias de funcionamiento

No se incluyen capturas falsas. Diego debe ejecutar el entorno sembrado y agregar
capturas reales de:

1. Login.
2. Dashboard residente.
3. Zonas comunes.
4. Reserva con estado `APPROVED`.
5. Invitado guardado.
6. Dashboard de vigilancia.
7. Detalle con residente, unidad e invitados.
8. Consola con pruebas aprobadas.
9. Pipeline CI en verde.

Nombre sugerido: `01-login.png` a `09-ci.png`. Evite mostrar secretos, tokens o
contraseñas.

## Guion de video (2–3 minutos)

1. Mostrar rama y aplicación abierta.
2. Ingresar como residente, reservar una zona y agregar invitado.
3. Cerrar sesión e ingresar como vigilancia.
4. Filtrar reservas, abrir el detalle y mostrar unidad e invitados.
5. Mostrar brevemente `npm run test` y el pipeline.
6. Cerrar indicando alcance y limitaciones reales.
